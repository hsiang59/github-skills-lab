# 程式碼模板

此目錄包含可重用的程式碼模板和提示範例，幫助你更有效地使用 GitHub Copilot。

## 模板類型

### 1. 函數模板
基本函數結構和文檔字串格式

### 2. 類別模板
類別定義和方法結構

### 3. API 模板
常見的 API 實作模式

### 4. 測試模板
單元測試和整合測試模板

## 使用方式

1. 複製所需的模板到你的專案
2. 填入具體的細節和需求
3. 讓 Copilot 根據模板生成程式碼
4. 根據需要調整和擴展

## 提示技巧

模板中已包含最佳實踐的提示格式：
- 清晰的文檔字串
- 型別註釋
- 使用範例
- 邊界條件說明

## 自訂模板

你可以基於這些模板創建自己的模板庫，並根據專案需求進行調整。
