# 程式碼範例

此目錄包含展示 GitHub Copilot 各種功能的程式碼範例。

## 目錄結構

- `python/` - Python 語言範例
- `javascript/` - JavaScript/TypeScript 範例
- `java/` - Java 語言範例

## 範例分類

### 1. 基本功能
- 程式碼自動完成
- 函數生成
- 註釋生成

### 2. 資料處理
- 資料清理
- 資料轉換
- 資料分析

### 3. API 整合
- REST API 客戶端
- 資料庫操作
- 外部服務整合

### 4. 演算法實作
- 排序演算法
- 搜尋演算法
- 資料結構

## 使用方式

1. 選擇你感興趣的範例
2. 在 IDE 中開啟檔案
3. 觀察 Copilot 如何基於現有程式碼提供建議
4. 嘗試修改和擴展範例

## 學習建議

- 先閱讀程式碼，理解其結構
- 嘗試添加新功能，觀察 Copilot 的建議
- 比較不同的實作方式
- 實驗不同的提示技巧
