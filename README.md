# GitHub Copilot 學習課程

歡迎來到 GitHub Copilot 學習課程！這個儲存庫包含了幫助你掌握 GitHub Copilot 的所有資源和練習。

## 📚 課程概述

本課程將帶領你從基礎到進階，全面學習如何使用 GitHub Copilot 來提升開發效率。

## 🗂️ 儲存庫結構

```
github-skills-lab/
├── exercises/          # 實作練習
├── examples/          # 程式碼範例
├── guides/            # 學習指南
├── templates/         # 程式碼模板
└── resources/         # 額外學習資源
```

## 🚀 快速開始

### 前置需求

- 已安裝 Visual Studio Code 或其他支援的 IDE
- GitHub Copilot 訂閱（個人版或商業版）
- 基本的程式設計知識

### 設定步驟

1. 複製此儲存庫：
```bash
git clone https://github.com/hsiang59/github-skills-lab.git
cd github-skills-lab
```

2. 在你的 IDE 中安裝 GitHub Copilot 擴充套件

3. 登入你的 GitHub 帳號並啟用 Copilot

4. 開始探索 `exercises/` 資料夾中的練習

## 📖 學習路徑

### 1. 基礎入門
- 了解 GitHub Copilot 的基本功能
- 學習如何撰寫有效的提示（Prompts）
- 掌握程式碼自動完成功能

### 2. 進階技巧
- 程式碼重構與優化
- 測試程式碼生成
- 文檔生成與註釋

### 3. 實戰應用
- 真實專案整合
- 最佳實踐與工作流程
- 協作開發技巧

## 💡 主要特色

- **實作導向**：包含大量實際練習
- **循序漸進**：從基礎到進階的完整學習路徑
- **多語言支援**：涵蓋 Python、JavaScript、Java 等多種程式語言
- **最佳實踐**：學習業界認可的使用方式

## 📝 練習說明
